# Security Policy

*Also available in French: [SECURITY.fr.md](SECURITY.fr.md).*

## Reporting a vulnerability

Report a suspected vulnerability through GitHub private vulnerability
reporting: [open a private report](https://github.com/VBlackJack/Heimdall/security/advisories/new).
The report stays visible to you and the maintainer only, and the fix is
discussed in that same thread. Do not open a public issue for a suspected
vulnerability.

Include in the report:

- affected version or commit;
- reproduction steps;
- expected impact;
- any relevant logs with credentials and hostnames redacted.

## Where to raise everything else

| Subject | Channel |
| --- | --- |
| Suspected vulnerability | [Private vulnerability reporting](https://github.com/VBlackJack/Heimdall/security/advisories/new) |
| Bug, crash, regression | [Issues](https://github.com/VBlackJack/Heimdall/issues) |
| Question, idea, feedback | [Discussions](https://github.com/VBlackJack/Heimdall/discussions) |

## There is no mail channel

This project publishes no contact address, and mail is not a supported way to
reach the maintainer. Addresses that appear in commit metadata are an artifact
of how Git records authorship, not an invitation: they are not monitored, and
mail sent to them receives no reply. Use one of the GitHub channels above.

The canonical threat model, known limitations, security controls, and security
test references live in [docs/SECURITY.md](docs/SECURITY.md).
