# Magellan par défaut, et un contraste tenu sur tous les thèmes

Magellan est désormais le thème d'une nouvelle installation. Cette version rend aussi lisibles le
texte, les points de statut, les contours et le terminal sur chaque thème et chaque couleur
d'accentuation : un audit de contraste des 17 thèmes a mesuré chaque paire de couleurs que
l'interface dessine, et les endroits insuffisants sont corrigés.

## Ce que vous verrez

- **Magellan est le thème par défaut.** Une nouvelle installation, ou un fichier de réglages qui n'a
  jamais enregistré de thème, démarre sur Magellan. Si vous aviez déjà choisi un thème, Drakul
  compris, vous le gardez.
- **Texte lisible sur les lignes survolées et sélectionnées.** Le texte d'erreur, d'avertissement,
  de succès, d'information, d'accentuation et le texte secondaire restent lisibles quand la ligne en
  dessous est survolée ou sélectionnée, ainsi que sur les cartes. Le texte secondaire gris de
  Dracula, difficile à lire, est plus clair.
- **Les couleurs de statut écrites en texte utilisent leur teinte lisible.** Les boutons d'arrêt des
  outils réseau, les lignes d'état, les entrées Supprimer des menus, les icônes des dialogues et les
  résultats d'audit n'utilisent plus les couleurs de statut brutes, trop pâles sur certains thèmes.
- **Les couleurs d'accentuation suivent votre choix partout.** Avec une couleur d'accentuation
  choisie dans les Paramètres, le texte d'accentuation, la ligne sélectionnée, le badge des sessions
  locales et les contours de focus prennent aussi cette couleur, et les contours restent visibles
  avec chaque accentuation.
- **Les boutons principaux restent lisibles au survol et à l'appui.** Sur les thèmes clairs, le
  survol assombrit désormais le bouton au lieu de l'éclaircir.
- **Les points de statut se voient mieux.** Les points de l'arborescence des sessions et des
  propriétés de session ressortent sur les lignes survolées et sélectionnées, et une session locale
  affiche désormais un anneau gris visible.
- **Les couleurs du terminal sont lisibles dans tous les schémas.** Le terminal renforce toute
  couleur trop pâle pour son fond, et sa barre de recherche suit désormais le schéma de couleurs
  utilisé.
- **Corrections plus petites.** Les séparateurs des lignes d'état des outils, le bandeau d'alerte
  ARP, le badge des outils externes, les points d'étape de l'accueil, l'indicateur de diffusion,
  l'outil Notes et les puces de statut de l'import RDP se lisent mieux.
