# Le message de fin de session SSH réapparaît, et Reconnecter fonctionne sur une connexion rapide

Une petite version, avec deux corrections SSH trouvées en vérifiant v2026.100201 à l'oeil.

## Le message de fin de session est visible

Quand une session SSH se terminait, Heimdall affichait un message avec Reconnecter,
Modifier le profil, Voir la sortie et Fermer. Il était dessiné sous le terminal, qui le
recouvrait : on voyait les dernières lignes du terminal et le bouton Reconnecter de
l'en-tête, rien d'autre. Il en allait de même pour le compte à rebours de reconnexion et
pour l'écran de connexion.

Le terminal s'efface désormais tant que l'un d'eux est affiché. Après une déconnexion
côté serveur, vous voyez "Session déconnectée de manière inattendue." avec ses boutons,
et Voir la sortie fait revenir le terminal avec tout ce que le serveur a affiché.

## Reconnecter fonctionne sur une session ouverte avec Ctrl+K

Une session ouverte en tapant une adresse dans la connexion rapide (Ctrl+K) n'est pas
enregistrée dans votre liste de sessions. Son bouton Reconnecter, dans la session et dans
son en-tête, la cherchait dans cette liste, ne la trouvait pas, fermait l'onglet et
affichait "Session introuvable dans l'inventaire." Il se reconnecte désormais à l'adresse
que vous aviez tapée, comme le faisait déjà Reconnecter dans le menu de l'onglet.
