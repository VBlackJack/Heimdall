# Un dossier de données à part pour les tests, et des échecs de compilation plus clairs

Une petite version pour celles et ceux qui compilent, testent ou contribuent à Heimdall. Rien ne
change dans l'usage quotidien de l'application.

## Pour les testeurs et les contributeurs

- **`Heimdall.exe --data-dir <dossier>` lance une instance avec ses propres profils, paramètres,
  journaux et bibliothèque de commandes,** à côté de celle de tous les jours. Rien n'est lu ni
  écrit dans votre propre profil, et les deux instances ne se passent pas la main. Sans l'option,
  rien ne change.
- **Une passe de tests en échec du script de build dit désormais pourquoi :** chaque test en échec
  s'affiche avec son message et ses valeurs attendue et obtenue, et toute la sortie est gardée dans
  `Dist\logs\tests-<version>.log`. Le script s'arrêtait sur le premier échec avant de l'afficher.
- **`scripts/Invoke-Mutant.ps1`** vérifie qu'un test attrape vraiment un changement : il casse le
  code exprès, lance les tests, restaure le fichier et recompile toujours, si bien que les binaires
  ne restent jamais cassés.
- **`scripts/Update-DocumentedKeyCount.ps1`** écrit le nombre de clés de traduction dans les
  documents qui le citent, ce qu'un test vérifie à chaque changement des catalogues.

La liste complète se trouve dans [docs/CHANGELOG.md](https://github.com/VBlackJack/Heimdall/blob/v2026.101501/docs/CHANGELOG.md).
