# Applications Citrix abonnées, réimport sans doublons et réglages Workspace

L'import depuis un magasin Citrix Cloud / Workspace récupérait jusqu'ici tout le catalogue en plus
de vos applications abonnées, et chaque nouvel import dupliquait les sessions existantes. Cette
version n'importe que les applications abonnées, met à jour les sessions existantes sans les
dupliquer et ajoute des réglages optionnels pour Citrix Workspace.

## Ce que vous verrez

- **Applications abonnées uniquement.** L'analyse du cache local Citrix Workspace n'importe plus
  que les applications auxquelles vous êtes abonné dans les magasins Citrix Cloud / Workspace, en
  ignorant le reste du catalogue. Les magasins plus anciens dont le cache n'indique pas d'état
  d'abonnement continuent d'être importés comme avant.
- **Le réimport met à jour au lieu de dupliquer.** Relancer l'import Citrix retrouve vos sessions
  Citrix existantes grâce à leur identifiant Citrix et rafraîchit leurs paramètres de lancement sur
  place. Vos noms personnalisés, dossiers/groupes, notes, étiquettes et favoris sont conservés,
  aucune session n'est supprimée, et le résumé indique le nombre d'applications ajoutées, mises à
  jour ou déjà à jour.
- **Réglages Citrix Workspace optionnels et analyse en arrière-plan.** Dans **Paramètres > Avancé >
  Outils et intégrations**, vous pouvez désormais indiquer un chemin optionnel vers
  `SelfService.exe`, un dossier de cache SelfService personnalisé et un préfixe de fichier de
  magasin pour n'analyser que les fichiers `<préfixe>*_Cache.xml` correspondants lorsque plusieurs
  magasins coexistent. L'analyse du cache s'exécute également hors du fil d'interface afin que la
  fenêtre reste fluide sur les caches volumineux.
