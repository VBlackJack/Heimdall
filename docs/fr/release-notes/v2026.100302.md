# Modifier le profil fonctionne sur une connexion rapide

Une version d'une seule correction, à la suite de v2026.100301.

## Modifier le profil sur une session ouverte avec Ctrl+K

Une session ouverte en tapant une adresse dans la connexion rapide (Ctrl+K) n'a pas de
profil enregistré. Quand elle se terminait, son bouton Modifier le profil en cherchait
un, ne trouvait rien et affichait "Session introuvable dans l'inventaire."

Il ouvre désormais la fenêtre de session remplie avec ce que vous aviez tapé, la même
fenêtre que "Enregistrer comme profil..." dans le menu de l'onglet. Vous pouvez y
corriger les réglages et les garder comme profil.
