# Connexion SSH avec code de verification

Le terminal SSH integre peut demander un code de verification ou une autre reponse
keyboard-interactive apres verification de la cle d'hote. Il prend aussi en charge
une cle privee suivie d'un code, ou un mot de passe suivi d'un code.

L'invite indique le serveur et le compte et masque la reponse. Le code sert uniquement
a la tentative en cours ; il n'est enregistre ni dans le profil ni dans le coffre.
Annuler la connexion ferme l'invite. Une reponse interactive refusee termine la
tentative sans reprise automatique avec Plink.

Cette evolution concerne le terminal integre utilisant SSH.NET. Les connexions SFTP,
l'authentification des passerelles SSH, leurs diagnostics et les sessions utilisant
Plink pour le transfert d'agent conservent leur chemin d'authentification actuel.

## Validation

- Compilation Release et formatage valides ; les 12 596 tests locaux passent.
- Huit controles sur un serveur OpenSSH/PAM isole : code correct ou incorrect,
  annulation utilisateur et annulation par jeton, avec ou sans mot de passe PAM prealable.
- Controles WPF : validation de la reponse, annulation de l'invite et effacement du champ.
- Quatre connexions sur deux cibles RDP Windows reelles, avec reutilisation de deux
  controles. Les deux controles ont ete liberes apres cinq minutes d'inactivite.
  Le banc isole mesurait environ 345 Mio connecte, 75 Mio apres fermeture et 36 Mio
  apres expiration. Ces chiffres ne mesurent pas l'application Heimdall complete.

La passe RDP ne couvre ni RD Gateway, ni reprise apres coupure reseau, ni transfert
de donnees par peripherique redirige.
