# Heimdall v2026.062901

## Français

### Nouveautés
- Coffre protégé par un mot de passe maître (chiffrement au repos). Dérivation Argon2id
  et AES-256-GCM, modèle KEK/DEK ; activation, changement et désactivation depuis les
  Paramètres, avec migration des identifiants existants et écritures de configuration
  atomiques. Quand un mot de passe maître est défini, l'espace de travail est verrouillé
  au démarrage derrière un gate de déverrouillage.
- Verrouillage de l'espace de travail : verrouillage manuel et auto-verrouillage sur
  inactivité, avec overlay ; les sessions sont masquées plutôt que déconnectées (option
  de déconnexion au verrouillage).
- Déverrouillage du coffre par Windows Hello : une clé Hello liée au TPM déverrouille le
  coffre par biométrie/PIN en alternative au mot de passe maître ; repli sûr (fail-closed)
  sur le mot de passe maître, conditionné à la présence d'un TPM.
- Macros "expect" : une macro peut attendre un motif de sortie attendu avant d'envoyer
  l'étape suivante (wait-for-pattern), avec un éditeur de macros dédié.
- Journalisation de session par profil : surcharge tri-état (forcer activé / désactivé /
  hériter du réglage global) dans la fiche serveur.
- Navigateur de fichiers (SFTP/FTP) : Couper / Copier / Coller / Dupliquer avec gestion
  non destructive des collisions et copie côté serveur ; upload récursif de dossiers et
  dépôt ciblant un dossier ; coller entre deux volets (même serveur ou entre serveurs) ;
  coller depuis l'Explorateur Windows ; opérations de fichiers journalisées.

### Corrections
- Menus contextuels rendus uniformément en texte (sans icônes), de façon cohérente.
- Éditeur : protection contre des jeux de règles AvalonEdit cycliques (palette Dracula).
- Dépendance : mise à jour de System.Security.Cryptography.ProtectedData (10.0.5 -> 10.0.9).

## English

### Added
- Optional master-password vault (encryption at rest): Argon2id key derivation and
  AES-256-GCM with a KEK/DEK model; enable, change, and disable from Settings, with a
  migration engine for existing credentials and atomic config writes. When a master
  password is set, the workspace is locked at launch behind an unlock gate.
- Workspace lock: manual lock plus idle auto-lock with an overlay; locked sessions are
  masked rather than disconnected (opt-in disconnect-on-lock).
- Windows Hello vault unlock: a TPM-bound Hello key unlocks the vault by biometric/PIN as
  an alternative to the master password; fail-closed fallback to the master password,
  gated on TPM presence.
- Expect macros: a macro can wait for an expected output pattern before sending the next
  step (wait-for-pattern), with a dedicated macro editor.
- Per-profile session logging: a tri-state override (force on / off / inherit the global
  setting) in the server dialog.
- File browser (SFTP/FTP): Cut / Copy / Paste / Duplicate with non-destructive collision
  handling and server-side copy; recursive folder upload and drop-into-folder targeting;
  paste between two panes (same server or across servers); paste from the Windows Explorer
  clipboard; journaled file operations.

### Fixed
- Context menus render uniformly text-only, consistently across the app.
- Editor: guard against cyclic AvalonEdit rule-sets (Dracula palette).
- Dependency: bump System.Security.Cryptography.ProtectedData (10.0.5 -> 10.0.9).
