# A hardening release: safer imports and sharing, data you can no longer lose, and a screen-reader pass

This release closes the full audit of 2026-10-27. Most of it is not new features: it is places where
Heimdall could lose your data, trust something it should not have, or say the wrong thing. Please
read the upgrade notes at the end, because three of the changes need action from your team.

## What you will see

### Security

- **Imported profiles are checked at the door.** A Citrix ICA path must be a local `.ica` file, a
  network or device path in an imported key, ICA or shell field is cleared (and listed in the import
  summary) instead of being probed, and an imported Citrix profile with an ICA file now asks for
  confirmation before it launches anything.
- **External tool values stay one argument.** A value that would split into several arguments is
  refused, in the external tools and in the credential command.
- **The Command Library no longer re-reads its own output.** A value that looks like another
  placeholder is inserted as text and never substituted again, and values with a trailing line feed
  or stray spaces are refused instead of passing as a number or a host name.
- **The password generator copies secrets as sensitive data.** They stay out of the Windows
  clipboard history and the cloud clipboard, and closing the tool finishes a pending clear.
- **VNC is locked to its own window.** The local proxy needs a random token and the exact page
  origin, and a failed connect now says why instead of waiting.
- **Smaller doors:** the cross-server paste folder is private to you and swept at startup, the
  WebView2 bootstrapper must carry a valid signature before it runs, and the Notes editor's bundled
  libraries are updated past their published advisories.

### Your data is safer

- **The Hosts file editor keeps every line.** Comments, blank lines, aliases and the file's encoding
  survive a save. A backup is made first, a file changed behind your back is not overwritten, Add no
  longer invents a demo row, and unsaved edits are flagged before you close or reload.
- **Heimdall can restart from its backup.** A missing `settings.json` or `servers.json` is restored
  from its `.bak` instead of being recreated empty.
- **Shutdown finishes its work.** Closing Heimdall or logging off no longer skips the final saves,
  and the window state is kept at logoff.
- **Notes are not rewritten when you open them,** and `[[note links]]` are no longer escaped. A note
  is saved only after you changed it.
- **Command Library sync no longer deletes what it did not write.** Only your own content travels,
  deletions are carried as dated records, a conflicted pull takes the remote cleanly, and the
  shipped catalogue has the same identity on every machine.
- **Smaller files:** scan history is written atomically, a damaged network knowledge base is set
  aside rather than overwritten, the diagnostic log is bounded by age and size, and sync history
  keeps the newest 500 entries per remote.
- **Imports read more of what they are given:** a MobaXterm file with a byte order mark, RDCMan 2.7
  names, and an mRemoteNG file whose connections inherit from folders.

### Protocols

- **Telnet:** a session the server closes ends cleanly, the connect timeout is told apart from your
  cancel, TCP keepalive is on, writes are ordered, and ECHO, SGA and TTYPE are negotiated.
- **FTP** starts in the server's working directory and reports why a connect failed.
- **VNC** clipboard text keeps its accents and non-Latin characters, and the page is translated.
- **Credential checks stop guessing.** The direct MySQL and MSSQL checks and the gateway VNC check
  now show "Not tested" because they cannot perform a login, and the gateway checks accept a result
  only on a positive marker, so `command not found` is no longer read as a default password.
- **Smaller fixes:** the Citrix window capture survives multi-user hosts, the SMB server name is
  read from the right line, and the cron calculator ORs the day fields, honours `a-b/n` and accepts
  month and day names.

### Installer and release

- **The MSI orders versions by year.** Two same-day builds no longer install side by side and a 2027
  build is not refused as older.
- **Upgrades clean up after themselves.** The Inno Setup installer removes vendored files that a
  release dropped and recognises a per-machine install, and the per-machine MSI keys its components
  under the machine.
- **A Standard build never runs a leftover WebView2 runtime.** The edition is stamped into the
  program itself.

### Accessibility

- **The Notes tree, command palette, post-connect steps, regex matches, tunnel gateways, RDP import
  chips and tag filters** are announced by their content instead of an internal class name.
- **The vault dialogs give the keyboard focus back** after a failed password, and five more dialogs
  open with the focus on the right field.
- **Tab walks the Web, SSH and RDP headers left to right,** and the key, certificate, password and
  gateway forms follow reading order.
- **Save errors are announced,** tall dialogs fit a 768 px screen, and SFTP queue buttons name their
  transfer.
- **Hosts editor:** the Problem cell stays readable on a selected row.

### Languages

- **Spanish for the whole shipped Command Library** (527 actions), and the debloat pack is written
  in English with French and Spanish blocks.
- **Fewer English leftovers:** the schedule text in the Scheduled grid, macro editor errors,
  certificate texts, durations in reports, the quick file server pages, the VNC page and the
  runbook variable help now follow the interface language. Detected tool names show as names, and
  the HTML audit report states its real language.
- **Spanish columns** in the main window are wide enough for their text.

### Also

- The Command Library action editor shows the Platform and Risk of the action again when you edit,
  duplicate or create one, and keeps a parameter's quoting mode when you save.
- An optional parameter left empty now drops its own flag (`-Title`, `--output`) with it.
- Closed tool tabs release their memory, and startup skips hashing the shipped files while they are
  unchanged.

## Upgrade notes

- **Every teammate who shares a Command Library must upgrade.** Deletions now travel as tombstones
  instead of an older build removing every file it did not write. An older build that syncs the same
  folder still deletes files it does not know, and it skips a synced user template whose parameter
  carries the new `flag` field.
- **Shared post-connect approvals are asked again once.** The approval is now bound to the host,
  ports and user names, so each shared session with post-connect commands asks one more time.
- **mRemoteNG import skips unknown protocols** (they used to become RDP sessions), and a connection
  that inherits its credentials takes the parent folder's, not its own stale ones.
- **A Telnet session closed by the server no longer reconnects by itself.** Only a dropped
  connection does.
- **The MSI ProductVersion scheme is now `yy.M.DDseq`** (for example 26.10.2901). Install this MSI
  over the old one as a normal upgrade; the new number is higher than every earlier build.
- **Direct MySQL/MSSQL and gateway VNC default-credential checks show "Not tested"** instead of a
  guess, and a report with such rows no longer says everything looks secured.
