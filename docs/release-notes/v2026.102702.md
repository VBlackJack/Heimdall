# Command Library finishing touches: the right button leads, and screen readers hear the rows

This release completes the usability review of the Command Library started in v2026.102701. The
remaining points were smaller, but several of them changed what you can actually do: in a tab with
no terminal the highlighted button was the one that could not work, and Enter or Ctrl+Enter in a
runbook could copy or send a command you could not see.

## What you will see

- **The button that can run is the highlighted one.** In a tab with no terminal, Copy is now the
  filled button and Send to Terminal an outline, in the command detail and in a running runbook.
  With a terminal, Send leads again. Send stays visible so its tooltip can say why it is disabled.
- **History, Runbooks and the favorites filter show when they are on**, with an accent outline, and
  a screen reader hears ", on" after their name.
- **Enter in a runbook variable no longer copies the hidden command.** While a runbook was running,
  Enter copied the command detail hidden behind it, and Ctrl+Enter sent it to the terminal. Copy,
  Send and Insert now only act on the command detail when it is shown.
- **No red error before you type.** A required field that starts empty no longer shows its error as
  soon as you select the command; Copy and Send stay disabled and say why. A default value that is
  wrong still shows its error at once.
- **Screen readers hear the rows by their content.** Parameters, examples, links, broadcast targets,
  runbook variables and the steps of the runbook editor used to be announced by an internal class
  name.
- **Titles line up**, whatever the risk badge in front of them, and Duplicate has its own icon
  instead of the Copy one.
- **Tab follows the screen**: search, filters, list, the command's buttons, then the header from left
  to right.
- **The Notes sidebar keeps its width** between sessions; the saved width was never read back.

The full list is in [docs/CHANGELOG.md](https://github.com/VBlackJack/Heimdall/blob/v2026.102702/docs/CHANGELOG.md).
