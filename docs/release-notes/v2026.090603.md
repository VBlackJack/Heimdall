### Changes

**The last four findings of the SSH audit, and its documentation**

The SSH audit of 2026-09-06 is now fully processed: 43 findings, 42 fixed, one refuted by
measurement. This release ships the last four fixes and the documentation of the whole audit.

- **Connecting through a Plink tunnel is faster.** The port bind wait slept a full interval
  (two seconds by default) before its first probe, so every Plink fallback connect paid that
  interval on top of the establishment delay, with the already-consumed password file still on
  disk. The loop now probes first and waits only between attempts.
- **Closing a tab while the host key prompt is open leaves nothing behind.** A session disposed
  while its connect was still resolving the host key, or still in the key exchange, went on to
  connect and left a client that nothing owned. The connect is now abandoned at that point and the
  client released.
- **A second-factor prompt is reported as such.** When a server asks for a verification code after
  the password, the failure names the question instead of blaming the password. Only a password
  prompt receives the stored password; entering a second factor is not supported.
- **The known_hosts start-up sync no longer hashes hashed entries against each other.** A hashed
  entry can only match the identical entry, yet each one was hashed under every stored salt: a
  2000-line hashed file against 2000 stored entries took 19 seconds and rewrote the settings 2000
  times. It now takes a few tens of milliseconds, and trust changes are written in one batch per
  quiet window instead of one write per line.
- **Documentation.** The user guide, security notes, feature list, architecture notes and
  troubleshooting guide describe every behaviour the audit changed, in English and French, and
  the README gains a line on auditable trust.
