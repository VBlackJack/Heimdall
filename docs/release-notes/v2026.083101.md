## Français

### Changement

- Le Hacker Simulator a été retiré de Heimdall. Son interface, ses scénarios, ses playlists,
  ses paramètres, ses traductions et ses ressources embarquées ne sont plus distribués.
- L'inventaire intégré compte désormais 58 outils. Aucun autre outil n'a été retiré.

### Pourquoi

Ce retrait fait notamment suite à des signalements Windows Defender. Ces signalements n'ont pas
été reproduits et cette version ne revendique donc pas de verdict antivirus.

### Mise à niveau

Aucune action n'est requise pour les autres outils, les connexions ou les paramètres existants.

## English

### Changed

- Removed the Hacker Simulator from Heimdall, including its WPF views, scenario and playlist
  catalogs, persisted settings, registry route, localization, theme and icon resources, and
  packaging declarations.
- The built-in tool inventory is now 58. No other tool was removed.
- Added a regression guard that rejects translated locale keys which are unreachable from the
  product.

### Upgrade note

No action is required for the remaining tools, connections, or existing settings.

A reported Windows Defender alert contributed to the removal decision. The alert was not
reproduced, so this release does not claim an antivirus verdict.
