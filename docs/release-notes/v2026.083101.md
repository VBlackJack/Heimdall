### Changed

- Removed the Hacker Simulator from Heimdall, including its WPF views, scenario and playlist
  catalogs, persisted settings, registry route, localization, theme and icon resources, and
  packaging declarations.
- The built-in tool inventory is now 58. No other tool was removed.
- Added a regression guard that rejects translated locale keys which are unreachable from the
  product.

### Upgrade note

No action is required for the remaining tools, connections, or existing settings.

A reported Windows Defender alert contributed to the removal decision. The alert was not
reproduced, so this release does not claim an antivirus verdict.
