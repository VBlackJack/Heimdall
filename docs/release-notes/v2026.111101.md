# Fewer ways to lose work, and SSH agents that no longer exhaust the server's patience

A release of fixes. Two come from the same user report as the previous release: a folder that would
not collapse, and SSH sessions refused when an agent holds several keys. The others come from a
review of the code that looked for places where Heimdall could lose work or skip a safeguard.

## What you will see

### Session tree

- **A folder that holds the selected session collapses again.** With a session of the folder
  selected, the arrow turned but the sessions stayed on screen.

### SSH

- **An agent key now costs one attempt.** Each RSA key of an SSH agent, Pageant for example, was
  offered three times in a row before the next key. With two RSA keys and the wrong one first, a
  server that allows three attempts refused the session. Every key is now offered once with the
  modern signature before any older signature is tried. The same keys are offered as before.
- **The "Too many authentication failures" message says how many keys the agent held,** and reminds
  you that a password or a key file saved on the session is tried first and counts too. The
  troubleshooting guide has a new entry.

### Work that is no longer lost

- **Closing Heimdall asks first.** With an unsaved file in the embedded editor, unsaved edits in the
  hosts file editor, a remote file edited over SFTP or a transfer still running, closing the main
  window dropped everything without a question. It now asks, pane by pane, as closing a tab already
  did.
- **The embedded editor cannot overwrite a file it failed to open.** A file over 16 MB, or one that
  could not be read, showed an error text in the editor; saving wrote that text over the file. Such
  a file now opens read-only and the save is refused.
- **Notes:** when a note cannot be saved, Heimdall no longer moves to the next note as if it had
  been. It asks whether to keep the note open or discard the changes.
- **Password generator presets:** a presets file that cannot be read is left untouched, and the tool
  says so. It used to be replaced by an empty one.
- **Reconnect with a filter active:** the tab closed and never came back when the search or a filter
  was hiding the session.
- **Tabs of shared sessions are restored at the next start,** like the others.

### Safeguards

- **Workspace lock covers detached windows.** A session detached into its own window stayed visible
  and usable while the workspace was locked. Detached windows are now hidden on lock and shown again
  on unlock, and "disconnect on lock" applies to them.
- **A web session asks before starting a local program.** The "open externally" button of a web
  session started the program named by the profile without asking, even for a profile received from
  someone else. It now asks once per tab and shows the program and its arguments.
- **The confirmation of an imported local shell shows everything it will run:** elevation first,
  then the arguments and the working directory.
- **Command library sync never replaces a built-in command.** A synced file could replace a shipped
  command and lower its danger level. Such an entry is now skipped and reported.
- **Importing settings:** X11 auto start, the Citrix SelfService path and the PowerShell execution
  policy are flagged as sensitive in the preview. A Citrix SelfService path on a network share is
  refused.
- **Private keys:** a private key copied from the SSH key or certificate generator stays out of the
  clipboard history and is cleared after 30 seconds, when the tool closes and when Heimdall exits. A
  file holding a private key is written readable by your account only.

## Upgrade notes

- **Closing Heimdall can now ask questions.** If a pane holds unsaved work, answer its prompt or
  cancel the close. With the workspace locked nothing is asked and the close behaves as before.
- **The diagram editor is not asked at exit:** its unsaved work is offered again at the next start,
  as before.
- **A web session profile you received, with an external program set, asks before the first
  external launch of each tab.** Profiles you created or saved yourself are not affected.
- **A Citrix SelfService path on a network share is no longer used.** Heimdall falls back to the
  installed SelfService. A mapped drive letter still works.
- **A synced command file that targets a built-in command is reported at each sync** until the file
  is removed from the synced folder.
