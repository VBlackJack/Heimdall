# Edit profile works on a quick connection

A one-fix release, following v2026.100301.

## Edit profile on a session opened with Ctrl+K

A session opened by typing an address in the quick connect box (Ctrl+K) has no saved
profile. When it ended, its Edit profile button looked for one, found nothing and said
"Session not found in the inventory."

It now opens the session dialog filled in with what you typed, the same dialog as
"Save as profile..." in the tab menu. You can correct the settings there and keep them
as a profile.
