# A separate data directory for test runs, and clearer build failures

A small release for whoever builds, tests or contributes to Heimdall. Nothing changes in how the
application behaves day to day.

## For testers and contributors

- **`Heimdall.exe --data-dir <folder>` runs an instance with its own profiles, settings, logs
  and command library,** beside your everyday one. Nothing is read from or written to your own
  profile, and the two instances do not hand over to each other. Without the option nothing
  changes.
- **A failing test run of the build script now says why:** each failing test is shown with its
  message and its expected and actual values, and the whole output is kept in
  `Dist\logs\tests-<version>.log`. The script used to stop on the first failure before printing
  it.
- **`scripts/Invoke-Mutant.ps1`** checks that a test really catches a change: it breaks the code
  on purpose, runs the tests, restores the file and always rebuilds, so the binaries never stay
  broken.
- **`scripts/Update-DocumentedKeyCount.ps1`** writes the number of translation keys into the
  documents that quote it, which a test checks on every change to the catalogues.

The full list is in [docs/CHANGELOG.md](https://github.com/VBlackJack/Heimdall/blob/v2026.101501/docs/CHANGELOG.md).
