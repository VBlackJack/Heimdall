# Closing with open sessions works again, and a session tree and tab strip you can shape

Two fixes and six changes to the session tree, the tab strip and the properties panel, all asked for
by someone moving a large inventory over from mRemoteNG. Every new behaviour is off by default,
except the lower tab strip.

## What you will see

### Fixes

- **Heimdall closes again while sessions are connected.** Since mid October, closing the window with
  a connected session did nothing: the confirmation failed before it was shown and the close was
  cancelled in silence. The confirmation is back. If it ever cannot be shown, Heimdall now says that
  the close was not confirmed.
- **An exhausted SSH authentication limit is named.** When a server cuts the connection after too
  many authentication attempts, Heimdall used to report an SSH protocol error. It now says "Too many
  authentication failures" and explains the usual cause: an SSH agent, Pageant for example, offering
  many keys before the right one. Load fewer keys in the agent, or give the session its own key
  file.

### Session tree

- **Compact session tree.** Settings, card "Session tree", "Compact session tree": rows are 24
  pixels high, which shows noticeably more sessions on one screen.
- **A click can show the tab of an open session.** Same card, "A click on an open session shows its
  tab": a single click on a session that already has a tab brings that tab to the front, or its
  window when the tab is detached. Double click and Enter still open a new tab.
- **Folders can be arranged by hand.** Alt+Up and Alt+Down move the selected folder among its
  siblings, and the right-click menu of a folder or a session has "Move up" and "Move down".
  Sessions could already be reordered with the same keys and by drag and drop; the menu entries make
  it visible.

### Tab strip

- **The tab strip is lower:** 37 pixels instead of 55. The session area gains the difference.
- **Folders on their own row.** With "Arrange tabs by folder" on, the tab menu has a new entry,
  "Show folders on their own row". The folders that have open tabs are listed above the strip, each
  with its colour, its name and its number of tabs. Choosing a folder shows its tabs and folds the
  others away. Pinned tabs and tabs outside any folder stay visible, and each folder comes back on
  the tab it last had selected.
- **A folded folder tells you when a session dropped.** Its header carries the mark of its worst
  tab: a grey ring for a disconnected tab, a red triangle for a failed one.

### Properties panel

- **Edit the basic fields in place.** The properties panel under the session tree has an "Edit
  here" button: display name, server, port, username and folder can be changed without opening the
  session dialog. Leaving the panel with unsaved changes asks whether to save or discard them. "Edit"
  still opens the full dialog.

## Upgrade notes

- **The tab strip is lower for everyone.** Nothing to set, and nothing is lost: the close button,
  the state marks and the folder chips keep their size.
- **Closing with connected sessions asks for confirmation again,** as it did before mid October. If
  you had got used to closing the sessions one by one first, that is no longer needed.
- **Folder order is saved in the settings,** per folder path. Renaming a folder keeps its place.
  Undoing a move with Ctrl+Z does not bring the manual rank back.
- **With folders on their own row,** the collapse entries of the tab menu are left out: the folder
  row replaces them. Ctrl+Tab cycles the visible tabs only.
