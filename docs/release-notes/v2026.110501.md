# A quieter import report for shared sessions, and SFTP uploads that say what they skipped

A small release with two fixes. The import report of a shared session source now tells a real
mistake apart from a deliberate choice, and an SFTP upload no longer reports success in silence when
the files it was given are gone.

## What you will see

### Shared sessions: the import report

- **A copied line is one finding, not three.** When a session reaches the host of another session
  of its folder, the one named after that host, the report shows a single "Likely copy error" on the
  session to fix. The same mistake used to show up as a name and host mismatch plus two duplicate
  hosts.
- **Warnings and information are told apart.** A session that goes through another bastion than the
  rest of its folder is now information: it is often deliberate. Every other finding stays a
  warning.
- **The source root counts warnings only.** A report with nothing but information shows no count in
  the session tree; it can still be opened from the right-click menu and from Settings.
- **The report header reads "2 warnings, 7 info",** each group names its severity, and Copy and
  Export CSV carry it.
- **Gateways are shown as the file writes them,** for example `[DAS]@bastion`, not the login the
  variable resolves to on your computer. The line is easy to find, and your login stays out of an
  exported report.
- **Clearer duplicate wording:** "Reaches app02, same host as session app01."

### SFTP

- **An upload whose local files vanished says so.** A selected or dropped file or folder that no
  longer exists, or cannot be read, used to be skipped without a word while the transfer still said
  complete. It is now listed in a status warning. The transfer stays complete on purpose: a retry
  cannot bring a missing file back.

## Upgrade notes

- **The session tree badge counts warnings.** A source that showed "11 issues" may now show
  "2 warnings", or no count at all when only gateway outliers remain. Open the report to see the
  information findings.
- **The import report CSV has a new first column, Severity.** A spreadsheet or a script that reads
  the columns by position needs to shift by one.
- **A second session to one host,** for example `db01-bis` next to `db01`, is now reported as a
  likely copy error instead of two duplicate hosts. It is still a warning.
