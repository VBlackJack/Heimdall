# Split panes act on their own session, and settings survive a damaged file

A release of robustness work across sessions, tunnels, SSH gateways, settings and
session logs. Most of it fixes things that went wrong quietly: the wrong pane closing,
a tunnel shown as healthy after its gateway rebooted, a damaged file losing your
trusted host keys.

## Sessions

- **Close and Reconnect act on the pane that asked.** In a split tab, after swapping,
  unsplitting or detaching panes, a dropped or closed session could close the whole tab
  or reconnect the other server. Every pane now knows its place, for every protocol,
  in floating windows too.
- **Closing a tab selects its neighbour,** not the last tab.
- **Split panes count against the session limit,** and a split tab dragged out of the
  strip stays there, with a message saying to unsplit it first.
- **The divider of a split remembers where you dragged it.**
- **Closed tabs stay closed,** and an automatic reconnect reports once, on its last
  attempt, instead of one dialog per failure.

## Tunnels and SSH gateways

- **Sessions that share a gateway and a target share one tunnel,** even when started
  together. Closing a tunnel that sessions still use asks first.
- **A tunnel whose gateway connection has gone is closed,** and the status bar says so.
- **A Plink tunnel that exits at once says why in seconds,** with Plink's own message,
  instead of waiting about 28 seconds. Plink no longer outlives Heimdall.
- **The gateway parent picker offers only parents that work,** and "None (direct
  connection)". A stored gateway password or passphrase can be cleared.
- **An imported profile can no longer replace a host key you trusted,** and gateway
  timeouts and DNS failures are named instead of "Unknown".

## Settings

- **A damaged settings or server file no longer stops Heimdall.** A last good copy is
  kept, loaded at startup if needed, and a message says the configuration was restored.
- **A settings import leads with what runs on this computer:** credential provider
  commands, tool paths, external tools and the Git sync address, in full.
- **Settings that were saved but never used now apply,** and Reset defaults keeps your
  external tools and the other things it should.

## Session logs

- **Transcripts can be deleted after a number of days.** Settings > Advanced >
  Diagnostics > "Delete transcripts older than", off by default. Only Heimdall's own
  transcripts are touched.
- **A log folder that stops answering no longer freezes the terminal.**

## Other protocols

- **VNC:** a server that asks for credentials Heimdall does not have says so instead of
  hanging; an open VNC session keeps the machine awake.
- **Citrix:** closing a session no longer closes your other published applications.
- **SSH:** a GPU driver reset no longer blanks every terminal, and a dead session stops
  keeping the machine awake.
- **RDP:** anti-idle survives an automatic reconnect.
- **SFTP:** a pane next to a terminal keeps its own status and its disconnect reason.
- **Health dots:** servers behind an RD Gateway or an SSH gateway are not probed, and
  every failure in the tooltip is in words.
- **Command library:** "Sync on startup" syncs, and says on the status bar when it fails.
