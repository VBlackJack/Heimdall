Cette version ferme trois chemins ou Heimdall agissait sans preuve : un tunnel SSH dont le port
local pouvait etre detenu par un autre processus, une passerelle Bureau a distance appliquee sans
verification, et des fichiers temporaires porteurs de secrets dont le nettoyage s'arretait apres
un seul passage.

### Tunnels SSH via Plink

- Heimdall verifie desormais que le port local du tunnel est bien ouvert par le processus Plink
  qu'il vient de lancer, par correspondance exacte d'identifiant de processus. Si le port est
  detenu par un autre processus, si rien n'ecoute, ou si le systeme ne permet pas de trancher,
  le tunnel est arrete au lieu d'etre presente comme etabli.
- A savoir : le chemin configure doit designer directement plink.exe. Un script ou un lanceur
  intermediaire ne peut pas etre atteste, et la connexion est refusee.

### Passerelle Bureau a distance (RDP)

- Quand un profil declare une passerelle RD Gateway, Heimdall verifie que le controle Bureau a
  distance a bien accepte le reglage : presence de la passerelle, ecriture, relecture et
  comparaison. Si une seule de ces etapes echoue, la connexion est arretee.
- Sans cette verification, un echec silencieux pouvait laisser la connexion partir en direct vers
  la cible, sans passerelle. Le message apparait dans le bandeau de statut de la session.

### Fichiers temporaires porteurs de secrets

- Le nettoyage des fichiers temporaires sensibles (fichier de mot de passe Plink, script
  d'amorcage WinRM) est desormais reprogramme tant qu'il reste un fichier a supprimer, au lieu de
  s'arreter apres un unique balayage. Un fichier qui n'est pas encore eligible a la suppression au
  premier passage est repris a l'echeance suivante.

### Journaux

- Les derniers journaux revelant l'etat d'une operation d'identifiants, cote Bureau a distance
  embarque, sont supprimes. Un test de garde empeche leur reintroduction.

Aucune action n'est requise a la mise a jour.
