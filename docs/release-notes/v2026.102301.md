# Subscribed Citrix apps, idempotent re-import, and Workspace settings

Importing applications from a Citrix Cloud / Workspace store used to pull every unsubscribed
catalog entry along with your subscribed apps, and running the import again duplicated every
session. This release imports only subscribed applications, updates existing entries in place on
re-import, and adds optional Citrix Workspace path and store filters in Settings.

## What you will see

- **Subscribed applications only.** Scanning the local Citrix Workspace cache now imports only the
  applications you are subscribed to in Citrix Cloud / Workspace stores, skipping unsubscribed
  catalog entries. Legacy stores whose cache files do not record a subscription state continue to
  import as before.
- **Re-import updates instead of duplicating.** Running the Citrix import again matches your
  existing Citrix sessions by their Citrix identifier and refreshes their launch metadata in place.
  Your custom display names, folders/groups, notes, tags, and favorites are kept, nothing is
  deleted, and the summary message reports how many applications were added, updated, or already
  up to date.
- **Optional Citrix Workspace settings and off-UI-thread scan.** Under **Settings > Advanced >
  Tools & integrations**, you can now set an optional `SelfService.exe` path, a custom local
  SelfService cache directory, and a store file-name prefix to scan only matching
  `<prefix>*_Cache.xml` files when several stores are present. The cache scan also runs in the
  background so the window stays responsive on large store caches.
