# Folders download over SFTP, transfers queue, and the session tree answers to typing

A release of interface work across the session tree, the settings, and the SFTP, SSH,
RDP and WinRM tabs. Most of it is about saying what is happening and what to do next.

## SFTP and FTP: whole folders, a transfer queue and real progress

- **Download takes folders.** The Download button, the right-click menu and
  Ctrl+Shift+D now accept folders, with everything they contain. Links are never
  followed: links, pipes and devices are left out, and the pane says how many were
  skipped. Entries can also be dragged from the remote list into the local browser.
- **A transfer started while another runs waits its turn** in a transfer queue below
  the list, instead of being refused. Each batch can be cancelled there. A batch that
  failed or was cancelled stays listed with its reason and runs again with Retry.
- **The progress bar measures the whole batch,** with the rate and the time left. It
  used to start over at every file.
- **The conflict dialog compares the two copies:** the size and date of the incoming
  and the existing file, which one is newer, and a choice that replaces only the newer
  ones.
- **Drag entries onto a folder row** to move them there on the same server. A name
  already in use gets a new name; nothing is replaced.
- **Clearer states.** A failed batch says how many files had arrived, a lost connection
  is named as such, an empty list says why, and a binary file opened by double click
  offers a download instead of opening in the editor.

## The session tree

- **Type the first letters of a name** to move to the next session or folder that starts
  with them. The same letter again steps through those rows.
- **The folder you moved to stays marked** when the focus goes to a menu or to the
  filter box.
- **The status dot fills when a session connects** and empties when it ends. It used to
  keep its previous shape, under a tooltip already giving the new state, until the list
  was scrolled or filtered.
- A wider focus ring, folder names the same size as their sessions, and a drop hint
  that no longer covers the zone that takes an item out of its folder.

## Settings

- **The Git sync access token is no longer written on each keystroke.** It is written
  when you leave its field: by clicking elsewhere, pressing Ctrl+S, switching tabs or
  closing Heimdall.
- Credential Guard and Windows Hello have their own card, the Git sync fields are
  disabled while sync is off, and the gateway and tool lists answer Enter, Delete and
  double click.

## SSH

- **Search in the terminal works again,** with a match counter. Plain URLs open with
  Ctrl+click.
- **The connecting overlay offers Cancel** and stays until the session is attached. A
  clean exit and a real failure each have their own message.

## RDP

- **A Reconnect button in the header** for endings that leave no overlay, and
  disconnect messages that say what to do next.
- Escape on the overlay no longer ends anything, and the status line shows its full text
  in a tooltip.

## WinRM

- **Authentication failures say what to do:** a refused password, access denied, a
  TrustedHosts refusal or a Kerberos problem, each with its own step. A refused password
  is no longer reported as a TrustedHosts problem.
- **The session editor warns before connecting** when a gateway downgrades HTTPS, when
  the certificate check is skipped, when the host needs TrustedHosts, and when no
  password is stored.

## Broadcast

- **In Selected panes mode, the count follows every change.** Selecting a pane or a tab,
  closing a tab and closing a pane inside a split now update "Selected panes (N)" and the
  tooltip of the broadcast button, which used to keep the previous count.

## Changing the interface language

- **More text follows a language switch without a restart:** the status lines in Settings
  (PIN, master password, auto-lock, credential provider, skipped update), the broadcast
  scope and its tooltip, the undo bar under the session tree, the Command Library (result
  counter, tooltips, filters, help and the badges on each command), the suffix of an RDP
  tab opened in a forced mode, and the window title.
