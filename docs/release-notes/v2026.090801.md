# Connection diagnostics and safer recovery

## Understand the SSH gateway route

The gateway editor now shows the complete parent chain and tests its current values without saving.
Each hop reports authentication, duration and an actionable failure. An optional destination step
checks TCP access from the final gateway. Stop the test or close the dialog to cancel it.

Tests use existing trusted host keys and refuse unknown or changed keys. Reports omit hostnames,
accounts, key paths and raw errors. A successful destination step confirms TCP access only; it does
not validate an RDP login or another application protocol.

## Recover from a disconnected session

- SSH and SFTP offer **Edit profile** directly in the disconnected session. Split views open the
  clicked pane's saved profile and keep the session available while you edit.
- RDP offers **Copy anonymized report** with UTC time, application version and available numeric
  RDP codes. The existing detailed report remains available separately.

## Safer transfers and connection lifetimes

- SFTP preserves the overwrite choice until publication, rejects late destination collisions and
  preserves the group owner before restoring permissions. FTP refuses exclusive-create uploads
  that it cannot guarantee. Privileged browsing preserves literal arrow names safely.
- Closing an external SFTP edit owner cancels pending opens before an editor or watcher can appear.
- SSH gateway reuse follows endpoint, account and credential changes. Network tools follow the full
  parent chain; handshakes support cancellation and every hop receives the configured keepalive.
- RDP trust removal waits for a successful settings save. Credential cleanup serializes ownership
  checks, cancelled embedded starts stay cancelled, and external launch requires a private file ACL.

## Validation and limits

Gateway diagnostics were exercised against two isolated OpenSSH servers, including trusted and
changed keys, authentication refusal, closed and silent TCP targets, cancellation and timeout.
SFTP publication checks used an isolated OpenSSH fixture. RDP validation covers automated code and
WPF tests; no interactive check against a live Windows RDP server was performed.

The existing keyboard-interactive fallback still does not guarantee verification-code MFA support.
