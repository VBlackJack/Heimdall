# External password vaults that work as expected, and a refreshed look

This release reworks how Heimdall gets passwords from KeePassXC and the other command-line password
managers: passwords now arrive exactly as they are stored, failures say what went wrong, and the
settings can be tested on a real entry. It also refreshes the look of the main window, makes the
interface easier to use with a keyboard and a screen reader, and hardens shared MobaXterm sessions.

## External password vaults (KeePassXC, KeePass2, Bitwarden, 1Password, pass)

- **Passwords arrive exactly as stored.** A password with an accented letter, or one that begins
  or ends with a space, reached the server changed. An unlock secret with an accent did not open
  the database. Both are fixed, including for tools such as KPScript that write in the Windows
  console code page.
- **Entry names are looked up as written.** An entry called `Srv R&D` was looked up as `Srv RD`
  and never found. Names ending with a backslash no longer break the command.
- **Failures say what went wrong.** A vault that does not answer in time now says so, with the
  delay, instead of the connection ending without a word; a bulk connect skips that server instead
  of stopping. A tool that is not installed is named as such. When a session is reopened at
  startup or from a failed tab's **Reconnect**, no dialog appears, and the reason is shown on the
  status line.
- **Test the settings on a real entry.** Settings > Security > External Credential Provider has a
  **Vault entry to look up** field beside **Test**. The result is green or red, says whether the
  username was found too, and warns when the value read spans several lines or begins or ends
  with a space. It works for the Windows Credential Manager as well.
- **SSH profiles.** A profile that signs in with a key still gets the vault's password, as a
  fallback for servers that want both. When the vault supplies the username (a username command,
  or the Windows Credential Manager), the SSH username of a profile is no longer required.
- **Easier to find.** The vault entry name of a server is on its General tab, under **External
  vault**, instead of the Info tab. The SSH credentials hint says the vault supplies the password.
  The status line says when the vault is being read.
- **Presets.** The selector shows the preset your command comes from, and asks before a preset
  replaces a command you wrote. The KPScript and pass presets turn on **Use only the first line of
  output**; the KPScript preset fails on a missing entry instead of returning its status line; the
  1Password preset uses `op item get`.
- A bulk connect asks the vault for one server at a time, so that slow database unlocks do not run
  past the timeout together.

The settings are explained in
[docs/SETTINGS-FAQ.md](https://github.com/VBlackJack/Heimdall/blob/v2026.101801/docs/SETTINGS-FAQ.md).

## Look and feel

- Refreshed main window: session tab strip with a quick connect button, session tree, status bar
  and launchpad.
- Every theme gains depth between surfaces and a hover tint, and the window title bar follows the
  theme.
- The embedded editor has a light syntax palette for light themes, and comments are readable on
  Dracula.
- Views follow a language or theme changed while they are open.

## Accessibility

- Status and result messages are announced by screen readers.
- Ctrl+Alt+Home leaves SSH, VNC and web sessions as it leaves RDP.
- Small buttons have a 24 pixel target, splitters have names, and the sidebar's tools read their
  names.
- Discard and delete confirmations keep your work when Enter is pressed, and a changed certificate
  is refused on Enter.

## Shared MobaXterm sessions

- A shared session gets its vault password by its host, so a session named after one machine that
  points at another no longer receives the first machine's password.
- Shared sources load without freezing the window when a share is out of reach, recover when a
  watched file comes back, and apply their settings without a restart.
- The import report says why a session was refused, and the source file read is bounded.

## Also

- SFTP: the local list has a hidden files toggle and accepts files dropped from Explorer.
- Tunnels: the Tunnels tab gets the same row menu and close button as the status bar panel.
- Citrix: a Citrix session can be split from its header.
- An open tool tab is no longer shown as failed.
- The WinRM check box labels wrap instead of being cut.

The full list is in [docs/CHANGELOG.md](https://github.com/VBlackJack/Heimdall/blob/v2026.101801/docs/CHANGELOG.md).
