# The SSH end-of-session message shows again, and Reconnect works on a quick connection

A small release with two SSH fixes found by checking v2026.100201 by eye.

## The end-of-session message is visible

When an SSH session ended, Heimdall showed a message with Reconnect, Edit profile,
View output and Close. It was drawn under the terminal, which covered it: you saw the
terminal's last lines and the Reconnect button in the header, and nothing else. The
same applied to the reconnect countdown and to the connecting screen.

The terminal now steps aside while any of them is shown. After a server-side
disconnect you see "Session disconnected unexpectedly." with its buttons, and View
output brings the terminal back with everything the server printed.

## Reconnect works on a session opened with Ctrl+K

A session opened by typing an address in the quick connect box (Ctrl+K) is not saved
in your session list. Its Reconnect button, in the session and in its header, looked
it up in that list, found nothing, closed the tab and said "Session not found in the
inventory." It now reconnects to the address you typed, as Reconnect in the tab menu
already did.
