# Language switch fixes, safer import preview, undoing a folder move keeps its place

This is a fix release. It fixes texts that kept
the old language after a language change, a language change that reported a failure although it had
worked, an import preview that could be fooled, and an undo that lost a folder's position.

## Security

- **The settings import preview now shows control characters.** Imported and current values (single
  values, lists, tool names and programs, shared source names and paths) are shown with a line break
  or a text-direction control made visible, so an imported file can no longer fake a line in the
  confirmation. Plain values look the same. A long value is still cut at 60 characters.

## Fixes

- **Changing the interface language no longer shows "Language not changed" when it worked.** With some
  tool tabs open (the Hash Generator, for one), the language switched but a failure was reported
  and the remaining parts were not updated. A part of the interface that fails to follow the switch
  is now logged and skipped, and the others still follow.
- **More texts follow a language change.** Tab close button names, group labels, the session load notice, the titles and
  ready status of open tool tabs (split and floating panes included), the "Ready" line of the main
  status bar, the settings search count and position hint, the open recipe tab (row count, error
  messages, field errors) and the sidebar tool list (category headings and tool rows). Expanded
  groups, favorites and a typed filter are kept. A tab you renamed, or a status a tool wrote itself,
  is left as it is.
- **Adding a program folder to the recipes no longer freezes the window.** The folder is checked in
  the background; the button is disabled meanwhile and a "Checking the folder..." line is shown.
- **Undoing a folder move in the session tree puts the folder back at its manual position**, instead
  of sorting it alphabetically among its old siblings. If the sibling it stood before is gone, it
  goes after the last sibling that has a manual position; if the old level has no manual order left, nothing is
  restored.

## Known limits

- Free-text statuses that a tool writes itself stay in the old language after a language change.

## Verified

- Every change was merged with the solution building with no warning, a clean code format check
  and green CI.
- Seen on screen with a test data folder: the open recipe tab and the sidebar reworded after a switch
  to English; a Hash Generator tab with its header, close button name, status bar line and settings
  search hint reworded after a switch to French, and a switch back to English with no dialog and no
  failure in the log; a program folder under C:\Windows added through the background check, with its
  notice.
- Not seen on screen: the import preview with a control character, and the undo of a folder move.
  Both are covered by automated tests only.
