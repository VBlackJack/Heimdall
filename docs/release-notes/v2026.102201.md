# A whole outline on the selected tab

The selected session tab looked cut on its right side, and on every shipped theme it had no
outline at all. This release draws the whole outline and removes a duplicate button from the tab
strip.

## What you will see

- **A whole outline on the selected tab.** The selected session tab now shows a visible outline
  on all four sides. Before, its right edge was clipped and the outline took the colour of the tab
  itself, so the tab read as cut open on one side. The same fix applies to the tabs inside the
  server dialog.
- **No "+" button at the end of the tab strip.** The "+" button at the right end of the session
  tab strip opened Quick Connect, exactly like the Quick Connect button in the toolbar, so it is
  gone. Quick Connect stays in the toolbar and on Ctrl+K. The tab list button still appears at the
  right end while the tabs do not all fit.

The full list is in [docs/CHANGELOG.md](../CHANGELOG.md).
