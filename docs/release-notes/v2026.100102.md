# Imports keep your unsaved Settings, and WinRM signs in when Heimdall starts from PowerShell 7

A small release with one fix that could cost you work, one that could stop a WinRM
session before it signed in, and two that make the window say the same thing
everywhere.

## Importing sessions no longer throws away unsaved settings

An import started from Settings (a .json or .rdp profile file, a MobaXterm, RDCMan or
mRemoteNG file, or the Citrix cache) reloaded the whole panel from disk, without a
word. A value typed a moment before came back to its saved value, a language or theme
being previewed reverted, and the panel no longer counted as changed, so nothing told
you there was anything left to save.

An import now reloads the session list only, and your pending edits stay where they
are until you save or undo them. SSH gateways brought in by a .json import still
appear in the gateway list at once. Sessions added by the network scanner are listed
the same way, without touching the Settings panel.

## WinRM: no more "untrusted publisher" question when started from PowerShell 7

When Heimdall was started from a PowerShell 7 session, the Windows PowerShell that a
WinRM tab runs inherited PowerShell 7's module folders and loaded its modules. Under
an AllSigned execution policy, it then stopped on "Do you want to run software from
this untrusted publisher?" before signing in. It now receives the inherited module
path without PowerShell 7's entries, every other entry kept, the way PowerShell 7
itself starts Windows PowerShell.

## One name for the delete key

The tooltip of the detail pane's Delete button, the hint line under its buttons and
the F1 help still said Ctrl+Del after the context menus had moved to plain Del. They
now all show the menus' label, in every language: Del, Suppr in French, Supr in
Spanish. Ctrl+Del keeps working.

## Counts read "1 session", not "1 session(s)"

- **The status bar words its counts by their number.** It read "1 sessions | 1
  tunnels"; it now reads "1 session | 1 tunnel".
- **Session, import and transfer messages do the same.** Bulk edits and their
  results, delete confirmations, imports and exports, the SSH gateway overview, PIN
  and vault lockouts, SFTP copy, cut, selection and skipped uploads, and the local
  file browser now write "Duplicated 1 item", "Moved 2 items" or "Try again in 1
  minute" instead of using "(s)".
- Messages that count several things at once, the network tools and the security
  audit keep their current wording for now.
