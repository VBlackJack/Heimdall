# The password generator, finished by hand

The release before this one rebuilt the password generator. This one is what a
day of actually using it found: a bar that did not work the way a hand expects,
a preset list that had outgrown the page, and a minimum strength that answered
questions instead of doing what it was asked.

## The placement bar works under the hand

The bar that says where the digits and special characters go had three separate
things wrong with it, and they only showed up while dragging.

Moving a cursor drew a whole new password on every mouse move. There was no way
to see what moving it had done, because the two passwords had nothing in common
but their shape. The characters the password is already made of are now put back
in the order being asked for, so one digit travels through a password whose other
characters hold still, under the mouse rather than after it. What is on screen
when the button comes up is what is kept. A batch of twenty is rearranged whole.

The character then stopped after one notch while the cursor carried on to the end
of the bar. The check that decided whether the characters set aside still
described the password on screen asked the saved positions to rebuild it, and a
preview is a display deliberately running ahead of the settings: the first
successful move made that question answer no, and every later move of the same
drag was refused.

The notches themselves were drawn only when a cursor moved, so they stood still
while the length slider ran. They also fell back to five evenly spaced marks
once the real places got close together, four of which sat where no character
could go. There is now one notch per place a character can take, counted from the
password on screen, and one arrow key press moves by one place: it used to move a
fixed two percent of the bar, which lands between two notches on any password
shorter than fifty characters.

## One row at the top, instead of a band of buttons and a drawer at the foot

The presets were eleven buttons across a band of their own, six showing at a time
and five hidden because they belonged to a mode you were not in, with the ones
you had saved on a second row underneath. Deleting one was a right click,
announced in the tooltip of the preset it would delete. The advanced options were
an expander at the foot of a page you had to scroll past the whole tool to reach.

All of it is now one row above the password: the mode, a preset list with Save
and Delete beside it, the minimum strength, and a button at the right that opens
the advanced options over the page. The list names the preset in force and says
Custom as soon as a control moves, rather than going on naming a preset the
settings have left. Asking for another password is not moving a control, so a
preset survives as many rerolls as you like.

## Asking for a minimum strength now sets the generator to reach it

Minimum strength was a question the tool answered rather than a thing it did. It
worked out whether the settings reached the minimum, generated at a bigger size
behind the scenes, and left the controls saying something else. When even the
biggest size could not reach it, nothing moved at all and you were left to find
the combination one slider at a time, with nothing to say which setting was in
the way.

Choosing a minimum now searches every shape the controls can be put in and writes
the first that reaches it, in one move. Measured on a syllable password of 24
characters with both safety options on: a hundred bits used to be refused, and is
reached at 32 characters with one more special character, for 102 bits. The old
search only ever tried the length, and never said so.

It can be taken back. The settings you had are kept, so clearing the minimum puts
them back exactly, and lowering it lowers them rather than leaving them where a
higher one put them. Move a control yourself and what is on screen becomes the
new starting point.

When nothing reaches it, nothing is changed and the line says how far these
settings do reach. A hundred and twenty eight bits cannot be guaranteed by
syllables however they are arranged, and being told the ceiling is 118 is the
difference between a refusal and an answer.

Two limits are deliberate. The search moves how much of a password there is,
never what it is made of: no character class is turned on, no word list changed,
no digit you asked for taken away. And a passphrase takes more words before it
takes any punctuation, because words are what a passphrase is for.

## A preset you can find, and settings kept only when asked

A saved preset appeared as an unlabelled button, showing only the ones belonging
to the mode you were in and saying that nowhere. Saving one in syllable mode and
coming back in random mode showed an empty row: the preset was on disk and out of
reach. Presets now live in the list at the top, under a heading, with a line
saying how many are saved in other modes.

There is a **Remember my settings** switch, off until you ask for it, under
Advanced. The tool reopens where you left it. What it keeps between runs is
sealed through the same protector as a session's password: the vault's key when
the vault is unlocked, this Windows account's own otherwise. A preset holds no
password, but it does describe the shape of the ones you make, your own set of
special characters, and whatever word you typed for the leet mode. A file written
before this is read once and written back sealed, so nothing saved is lost. A
sealed file belongs to the Windows account that wrote it: copied to another
machine or opened under another account, the presets in it cannot be read, and
the log says so rather than the tool starting empty without explanation.

## Two corrections to the release before this one

The two rows of the placement bar had stopped starting at the same place or being
the same length, so a cursor at half way on one sat nowhere near half way on the
other. The label widening released in v2026.091802 had matched a width belonging
to a column rather than to the label it aimed at. Both rows now size that column
together, in any language.

The generator panel resized itself while you used it. Two causes, both measured
on the width of the password box: the vertical scrollbar appeared as soon as the
content outgrew the panel and took its width off every control, and the readouts
column sized itself to its own contents, so a longer password in the recent list
moved everything on the left. The scrollbar's place is now always reserved and
the readouts column has a width of its own.

And `1 hours` is now `1 hour`.
