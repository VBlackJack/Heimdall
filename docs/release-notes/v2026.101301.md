# Session tabs arranged by folder

A release about the session tab strip. Tabs can now be arranged by the folder of their
profile, a folder folds into a chip, and one gesture switches from one set of machines to
another. The strip also stays usable with many tabs open, and the tab menu and the keyboard
reach more of it.

## Tabs arranged by folder

- **Right-click a tab, "Arrange tabs by folder".** The tabs of each folder sit side by side
  behind a chip with the folder's name and colour. Off by default, because it reorders the
  strip; the choice is saved. A reconnect, a renamed folder or a restored workspace all land
  in the right place.
- **A click on a folder's chip folds its tabs into it.** Selecting a tab of a folded folder,
  from the keyboard, the tree or a new connection, unfolds it.
- **"Collapse the other folders"** folds every other folder at once and keeps this one open.
  Tabs outside any folder stay visible. Thanks to the user who described the need in
  discussion #500.
- **"Close this folder's tabs"** closes a whole folder from the tab menu.

## Many tabs open

- **The selected tab scrolls into view** instead of staying past the right edge.
- **"All open tabs"**, at the right end of the strip when the tabs overflow, lists every tab,
  folded ones included. The mouse wheel scrolls the strip.
- **Ctrl+Tab skips a folded folder** instead of unfolding it.
- **Dropping a tab on the empty part of the strip moves it to the end** instead of splitting
  the displayed session.

## Tab menu and keyboard

- **The tab menu starts with Reconnect and ends with Disconnect,** which used to sit under the
  pointer. Its profile entries no longer vanish under a tree filter.
- **Shift+F10 and the Apps key open the menu of the selected tab.** Shift+F10 did nothing
  anywhere before, and it now opens the session tree's menu too.
- **Ctrl+F4 closes the active tab, from a terminal too.** Ctrl+W stays with the shell, and an
  RDP view keeps Ctrl+F4 for the remote desktop.
- **Middle-click closes a tab,** and **"Reopen closed tab"** brings back one of the last ten
  tabs you closed.
- **The close button of an inactive tab is easier to see.**

## Session threshold

- **Heimdall no longer refuses a session past the threshold.** A banner says how many sessions
  are open, and can be hidden. Refusing often came after the connection was made, and threw it
  away.
- **Connections are counted, not panes.** The SFTP pane that opens beside an SSH session used
  to count, so the default of 10 stopped an SSH user at 5 tabs.

## Tree filters

- **Reveal in tree, Duplicate session and the command palette find a profile the tree filter
  hides.** Reveal in tree clears the filters only when they hide the profile.
