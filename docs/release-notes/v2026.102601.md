# Magellan by default, and contrast that holds on every theme

Magellan is now the theme a new installation starts with. This release also makes text, status
dots, outlines and the terminal readable on every theme and accent colour: a contrast audit of the
17 themes measured every pair of colours the interface draws, and the places that fell short are
fixed.

## What you will see

- **Magellan is the default theme.** A new installation, or a settings file that never recorded a
  theme, starts on Magellan. If you already chose a theme, Drakul included, you keep it.
- **Readable text on hovered and selected rows.** Error, warning, success, information, accent and
  secondary text now stay readable when the row under them is hovered or selected, and on cards.
  Dracula's grey secondary text, which was hard to read, is lighter.
- **Status colours drawn as text use their readable shade.** Stop buttons of the network tools,
  status lines, menu Delete items, dialog icons and audit results no longer use the raw status
  colours, which were too faint on some themes.
- **Accent colours follow your accent choice everywhere.** With an accent colour picked in Settings,
  accent text, the selected row, the local session badge and focus outlines now take that colour too,
  and the outlines stay visible with every accent.
- **Primary buttons stay readable when hovered and pressed.** On the light themes the hover state now
  darkens the button instead of lightening it.
- **Status dots are easier to see.** The dots in the session tree and in the session properties
  stand out on hovered and selected rows, and a local session now shows a visible grey ring.
- **Terminal colours are readable in every scheme.** The terminal raises any colour too faint for its
  background, and its search bar now follows the colour scheme you use.
- **Smaller fixes.** Separators in the tool status lines, the ARP alert banner, the external tool
  badge, the onboarding step dots, the broadcast indicator, the Notes tool and the RDP import status
  chips all read better.

The full list is in [docs/CHANGELOG.md](../CHANGELOG.md).
