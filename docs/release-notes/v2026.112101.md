# The SFTP pane beside an SSH session takes the share you choose, and the splitter keeps where you drag it

This release makes the width of the SFTP pane that opens beside an SSH session a setting, and fixes the splitter
between two panes so that a drag is remembered and a double-click puts the panes back.

## What you will see

### SFTP pane width

- **A new setting chooses how much of the session area the SFTP pane takes.** Settings > SSH & SFTP > SFTP & X11,
  "SFTP panel width beside the SSH terminal", from 25 to 80 percent. The default is 33: the terminal takes two
  thirds, the SFTP pane one third. Before, the pane always took half.
- **The setting can be changed only when the SFTP browser and its automatic opening with SSH sessions are both
  on**, since it applies to that pane only.
- **It applies to the sessions you open after the change.** Tabs already open keep their split.

### Splitter between two panes

- **The position you drag the splitter to is the one remembered.** Before, Heimdall remembered the position
  from before the drag, so a split came back one drag late after a tab switch.
- **A double-click on the splitter after a drag puts the panes back.** Before, the panes did not move. The SFTP
  pane goes back to the share set in the settings, and a split you made yourself goes back to half and half.
- **Swapping the two panes keeps each pane's size.** The panes only change sides, and a double-click afterwards
  gives each one back its own share. Before, the sizes stayed in place while the panes moved, so a dragged split
  turned around.

## What to know before you upgrade

- **The SFTP pane now opens at one third of the session area, not half**, also on an existing installation. Set
  "SFTP panel width beside the SSH terminal" to 50 to keep the former layout.
- **The local shell with its local file browser still opens half and half**: the new setting does not apply to
  it.

## Dependencies

- SSH.NET 2026.0.1, YamlDotNet 18.1.0, and updates of packages used only by the tests.

## Verified

- On screen with a test data folder and a local SSH server: the setting shows 33 by default, 90 is refused at
  save, 40 is saved, and the field is disabled when the automatic opening is off; with the setting at 30, the
  SFTP pane opened at 30 percent of the session area.
- On screen, on the splitter fix before it was combined with the new setting: a drag to 28 percent is recorded
  as 28 percent, and a double-click after a drag puts the panes back at half and half, twice in a row, with no
  error in the log.
- Not tried on screen: the double-click on this release's build, where the SFTP pane goes back to the configured
  share rather than half; swapping the panes; the new setting in French and Spanish.
