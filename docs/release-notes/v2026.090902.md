# Easier session search and organization

The session tree makes active filters visible and easier to clear. The search field
now shows a short "Search" placeholder; its scope and Ctrl+F shortcut are in a tooltip.
Search results show the folder path and host address, and an empty result offers
actions to clear the search or reset all filters.

Selecting several sessions reveals Connect, Move and More actions. Dragging shows
the destination and session count, opens folders when hovered, and scrolls near the
tree edges. Undo restores the latest move, inline rename or session reorder during
the current application session, with checks for incompatible later edits.

## Fixes

- Alt+Up and Alt+Down reorder sessions correctly through WPF system-key events.
- Delete edits the name while renaming, including with multiple sessions selected.
- Selection notifications expose the updated selection to accessibility clients.
- Moving sessions across folders preserves their order in the tree.

Undo keeps one step and does not cover deletion. Folder undo uses the existing
staged settings and inventory migration; simultaneous external edits are not
protected by a transaction spanning both files.

Full-window pointer interaction, screen-reader speech and layout across DPI/theme
combinations were not exercised by the automated checks.
