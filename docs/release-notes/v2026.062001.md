### Command Library
- L'état du bouton « Envoyer vers le terminal » est plus clair, avec une aide visuelle pour la copie.
- Les exemples s'appliquent désormais au clic sur la ligne (Command Library et palette Ctrl+K).

### Fiabilité
- La palette Ctrl+K affiche l'erreur de régénération d'un snippet au lieu de vider le message silencieusement.
- Journalisation : les logs internes (TwinShell) sont enfin écrits dans le FileLogger en Release.
- Validation : le plafond d'exemples par action compte correctement les 3 catégories (commun / Windows / Linux).
