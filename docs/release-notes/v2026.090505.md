### Changes

**The sessions tree, audited and reworked**

- **A filter pass no longer throws keyboard focus out of the tree.** Every folder handed the
  tree a fresh list of its children after each filter pass, and a new list is a reset to WPF's
  container generator: every row under the folder was rebuilt and the focused one went with it.
  With the Connected filter on, any session connecting or disconnecting left the tree without a
  focused row, after which Shift+F10, Enter, Delete and F2 had nothing to act on. A folder now
  keeps one child collection for its whole life and edits it in place.
- **The detail pane follows the selection wherever it comes from.** The tree handlers wrote the
  pane's visibility directly, which severed the binding on the first click; a search with no
  match then left the pane open with a blank title and an inert Connect button. Both panes, and
  the tool pane's texts, are bound to the view model and nothing in the window writes them.
- **Names sort by the reader's alphabet.** Folders and sessions were ordered by code point, so a
  name starting with an accented capital sat at the bottom, below "Zurich". The tree, the folder
  pickers, the project list and the bulk-delete summary sort under the current culture.
- Every selected row carries the accent edge, so a second selected row no longer looks like a
  hovered one; the "No group" folder no longer opens an empty tooltip; session rows announce
  their keyboard gestures to assistive technology.

**Organise the tree by hand**

- **Folders take a colour.** The folder menu offers the eight palette colours project badges
  already use, plus a way back to the default. The colour paints the folder icon and is
  inherited by sub-folders until they choose their own; it follows a rename and goes with a
  deletion.
- **A folder can be moved by dragging it**, or from its "Move to" submenu. Dropped on another
  folder it becomes its sub-folder; dropped on the "No group" zone it returns to the top level.
  Sub-folders, sessions, colour and defaults travel with it. A drop onto the folder itself, one
  of its sub-folders or its current parent is refused; a name already taken under the target is
  reported as a rename would report it.
- **Sessions can be arranged within a folder.** A session dropped on another session row lands
  before or after it, with an accent edge showing the side while dragging; dropped on a row of
  another folder it changes folder and takes that position. Alt+Up and Alt+Down move the focused
  session one step from the keyboard.
- **A sort order of zero now means "no manual order"** and ranks after every ordered session,
  alphabetically among the other unordered ones. Before, zero ranked first, so every new session
  landed at the top of an arranged folder. An inventory that mixed hand-typed orders with
  untouched sessions sees the untouched ones move to the bottom of their folder; an inventory
  that never set an order keeps its alphabetical tree.

**Filters, keyboard and start-up**

- The filter menu gains a **Via gateway** facet, which keeps only the sessions routed through an
  SSH gateway, a missing gateway included, and a **Show gateway badge** preference: an inventory
  that routes everything through one gateway painted the same badge on every row. With the badge
  hidden, the row's hover text names the gateway; a missing gateway keeps its badge regardless.
- **Ctrl+A** selects every session inside an expanded branch. **Enter** on a focused folder
  opens or closes it. Screen readers hear the selection size once more than one session is
  selected.
- **The tree opens on the session that was selected at the last close**, with its detail pane
  in place. A selection cleared before closing is remembered as cleared.

**Three audit hypotheses, measured and closed**

- A row's automation peer kept listening to its session after the tree had discarded the row,
  because WPF replaces a discarded row's data context without raising the event the peer relied
  on. Every discarded row lived as long as its session, once a UI Automation client had touched
  the tree. The peer now lets go when the row leaves the screen.
- Ctrl+Down and Ctrl+Up dressed the row they walked onto as selected while the protected
  selection sat elsewhere; the row keeps the focus and loses the selected look.
- A reveal from the command palette could be taken for a multi-selection gesture when Ctrl was
  still down; every programmatic selection now bypasses the gesture handler.

**Remote Desktop**

- **The colour depth floor is 16 bits.** A profile or the RDP defaults accepted 8 bits and
  silently delivered 16; the bound is now 16 to 32, declared once and read by the settings
  loader, the profile validator and the server dialog. The mRemoteNG and .rdp importers bring a
  lower depth onto the floor, which is what the session got before.
