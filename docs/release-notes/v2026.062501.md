# Heimdall v2026.062501

## Français

### Nouveautés
- Exécution multi-sessions (MultiExec / broadcast). Diffuse ta saisie clavier vers
  plusieurs sessions à la fois, avec choix de portée : onglet courant, tous les onglets,
  ou une sélection de panes. Ciblage cochable par onglet et par pane, indicateur de
  portée, et confirmation avant une diffusion large. La diffusion passe par le garde
  anti-collage massif.
- Journalisation des sessions (nouvelle option globale). Deux formes selon le protocole :
  transcript texte par session pour SSH, Telnet et Local Shell ; journal d'événements
  connexion / déconnexion (avec raison et durée) pour RDP, VNC et Citrix. Fichiers rangés
  sous logs/sessions, rotation par taille, permissions restreintes.
- Authentification KeePassXC par fichier-clé. En plus du mot de passe, les coffres
  KeePassXC peuvent maintenant s'ouvrir avec un key-file.
- Menus contextuels enrichis sur l'arbre des serveurs et sur les onglets de session.

### Corrections
- Local Shell / WinRM : le prompt initial s'affiche désormais correctement. La sortie
  d'amorçage du terminal n'est plus perdue lorsque l'affichage s'abonne trop tard.
- Héritage de groupe : le type de connexion et l'environnement hérités sont maintenant
  réellement appliqués, et la précédence parent / enfant est corrigée.

## English

### Added
- MultiExec / broadcast: scope modes (current tab / all tabs / selected panes), per-tab
  and per-pane targeting, scope indicator, confirmation for wide broadcast, fan-out routed
  through the smart-paste guard.
- Session logging behind a single global toggle: per-session text transcripts for
  SSH / Telnet / Local Shell; connect/disconnect event log (reason + duration) for
  RDP / VNC / Citrix; single shared NDJSON event log, size rollover, restrictive ACLs.
- KeePassXC key-file authentication, in addition to password unlock.
- Enriched server-tree and session-tab context menus.

### Fixed
- Terminal: replay ConPTY bootstrap output to late subscribers, so the Local Shell /
  WinRM initial prompt is no longer dropped.
- Core: apply inherited ConnectionType / Environment and fix group-defaults precedence.
