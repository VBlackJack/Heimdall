# Web consoles and a properties panel

A release that adds web consoles as a connection type, for iLO, iDRAC, switch and NAS admin
pages, and a properties panel under the session tree. It also settles, in one place, whether a
profile goes through an SSH gateway.

## Web consoles

- **A new connection type, Web** (issue #558). A web console sits in the tree like any other
  session and opens in a tab. Its address is built from the profile's host, port, HTTPS or HTTP
  and an optional path. One browser profile is shared by every web tab, so a sign-in holds across
  tabs and restarts.
- **Self-signed certificates are asked once, then remembered,** per host and port, as for FTPS.
  A certificate that changes is asked again with a warning, and Enter does not accept it.
  `Settings > Security` lists the certificates trusted for good and forgets one.
- **The browser's own sign-in prompt** (Basic, NTLM) is answered from the profile, for its own
  host only. Sign-in forms inside the page are not filled. With the credential provider on, a
  profile that names a user gets the password from your vault.
- **Through an SSH gateway:** the console's tab goes through the gateway's tunnel with the
  console's real name, so its certificate, redirects and internal names all work. Every console
  behind one gateway shares one tunnel.
- **For a console too old for today's browsers,** a profile can open with an external program,
  for example an old portable browser. A button in the tab header, and on the panel shown when a
  console cannot be loaded, opens the current page externally.
- **A console opens at the zoom you last left it at,** kept per profile.
- **The reachability dot asks for the console's page** instead of only opening its port: a console
  answering with a server error shows as unreachable, with the code in the tooltip.
- **mRemoteNG HTTP and HTTPS connections import as web profiles.**

## Properties panel

- **The selected session's properties can be docked under the tree** (issue #557): protocol,
  address, authentication, user, SSH key, gateway, folder, environment, tags, latency and when the
  session was last opened. Turn it on from the filter menu, in `Settings > General > Session
  tree`, or with Ctrl+Shift+B.
- **Click a value to copy it,** or reach it with Tab and press Enter.
- **On a folder, or with several sessions selected,** the panel shows a summary instead: how many
  sessions, how many are connected, and how many use each protocol.

## SSH gateways

- **One rule decides whether a profile goes through an SSH gateway,** shared by the connection,
  the reachability check, the "via" badge and the gateway overview. A profile set to connect
  directly no longer shows a gateway it does not use, and a profile that inherits its gateway from
  its folder now shows it.
- **A split pane inherits its folder's gateway and SSH defaults,** as its tab always did. It used
  to open directly when the gateway came from the folder.
