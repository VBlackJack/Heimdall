# Heimdall v2026.062101

## Français

### Refonte de l'intégration des coffres de mots de passe

Cette version répare et étend en profondeur la récupération de mots de passe depuis
un gestionnaire externe — une fonctionnalité qui n'était jusqu'ici pas réellement
exploitable avec les modèles fournis.

- **Les outils interactifs fonctionnent enfin.** Un secret de déverrouillage
  optionnel (stocké chiffré via DPAPI) peut être transmis à l'outil via son entrée
  standard, ce qui permet à KeePassXC et `pass` de se déverrouiller sans
  intervention.
- **Récupération du nom d'utilisateur.** Une commande dédiée, optionnelle, peut
  résoudre le login en plus du mot de passe.
- **Nom d'entrée du coffre par profil.** Le nom recherché dans le coffre peut être
  découplé du nom d'affichage Heimdall.
- **Tous les protocoles couverts.** Telnet et VNC utilisent désormais le coffre, au
  même titre que SSH/SFTP, RDP/Citrix, WinRM et FTP.
- **Coffre natif Windows.** Nouveau fournisseur **Windows Credential Manager** (lit
  identifiant + mot de passe), sélectionnable à la place du fournisseur en ligne de
  commande.
- **Mode « première ligne » + préréglage KeePass2.** Une option ne conserve que la
  première ligne de sortie (utile pour KPScript et `pass`) ; un préréglage KeePass2
  (KPScript) a été ajouté.
- **Verrou Windows Hello.** Une vérification biométrique / code PIN optionnelle peut
  être exigée avant l'utilisation des identifiants stockés, en connexion simple
  comme en connexion multiple (fail-closed, fenêtre de grâce configurable).
- **Correctif.** Le bouton « Tester » des réglages utilise désormais le délai
  d'expiration configuré.

## English

### External vault integration overhaul

This release repairs and substantially extends credential retrieval from an
external password manager — a feature that was not genuinely usable with the
shipped presets until now.

- **Interactive vault tools now work.** An optional unlock secret (stored
  DPAPI-encrypted) can be fed to the tool via stdin, so KeePassXC and `pass` unlock
  non-interactively.
- **Username from the vault.** An optional separate command resolves the login in
  addition to the password.
- **Per-profile vault entry name.** The vault lookup name can be decoupled from the
  Heimdall display name.
- **All protocols covered.** Telnet and VNC now use the provider alongside
  SSH/SFTP, RDP/Citrix, WinRM and FTP.
- **Native Windows vault.** A new **Windows Credential Manager** provider (returns
  username + password) is selectable instead of the command-line provider.
- **First-line output mode + KeePass2 preset.** An option keeps only the first line
  of output (useful for KPScript and `pass`); a KeePass2 (KPScript) preset was added.
- **Windows Hello gate.** An optional biometric / PIN verification can be required
  before stored credentials are used, on both single and bulk connect (fail-closed,
  configurable grace window).
- **Fix.** The Settings "Test" button now uses the configured timeout.
