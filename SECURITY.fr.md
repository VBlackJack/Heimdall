# Politique de sécurité

Heimdall accepte les signalements de sécurité privés via le canal du mainteneur
utilisé pour partager ce dépôt. N'ouvrez pas de ticket public pour une
vulnérabilité présumée.

Ce dépôt ne publie pas actuellement d'adresse e-mail dédiée à la sécurité.
Si vous devez signaler une vulnérabilité, indiquez :

- la version ou le commit concerné ;
- les étapes de reproduction ;
- l'impact attendu ;
- tout journal pertinent, avec les identifiants et les noms d'hôtes expurgés.

Le modèle de menace de référence, les limitations connues, les mesures de
sécurité et les références des tests de sécurité se trouvent dans
[docs/fr/SECURITY.md](docs/fr/SECURITY.md).
